6. Problemas propuestos

En esta sección se muestran problemas en formato de carrusel. Usa los botones para avanzar o retroceder entre los ejercicios.

Problema 1

Si f(x) = 4x + 1, encontrar f(5).

f(5) = 4(5) + 1

Problema 2

Si g(x) = x² + 2, encontrar g(4).

g(4) = 4² + 2

Problema 3

Si h(x) = 5x - 7, encontrar h(3).

h(3) = 5(3) - 7

Problema 4

Si m(x) = 2x² - 1, encontrar m(2).

m(2) = 2(2²) - 1

Respuestas para comprobar

EjercicioRespuesta
f(5) = 4(5) + 121
g(4) = 4² + 218
h(3) = 5(3) - 78
m(2) = 2(2²) - 17
