4. Ejemplos

Ejemplo 1

Función:

f(x) = 2x + 3

Evaluar cuando x = 4:

f(4) = 2(4) + 3

f(4) = 8 + 3

f(4) = 11

Ejemplo 2

Función:

g(x) = x² - 5

Evaluar cuando x = 3:

g(3) = 3² - 5

g(3) = 9 - 5

g(3) = 4
