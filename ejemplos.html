4. Ejemplos

Ejemplo 1

Función:

f(x) = 2x + 3

Evaluar cuando x = 4:

f(4) = 2(4) + 3

f(4) = 8 + 3

f(4) = 11

Ejemplo 2

Función:

g(x) = x² - 5

Evaluar cuando x = 3:

g(3) = 3² - 5

g(3) = 9 - 5

g(3) = 4

Ejemplo 3

Función:

h(x) = 5x - 7

Evaluar cuando x = 2:

h(2) = 5(2) - 7

h(2) = 10 - 7

h(2) = 3

Ejemplo 4

Función:

m(x) = 4x² + 1

Evaluar cuando x = 2:

m(2) = 4(2²) + 1

m(2) = 4(4) + 1

m(2) = 16 + 1

m(2) = 17
