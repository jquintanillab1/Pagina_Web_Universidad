4. Ejemplos resueltos

Los siguientes ejemplos muestran cómo pasar de la función a una tabla de iteraciones.

Ejemplo 1 · Newton-Raphson clásico

Resolver x² − 2 = 0

Buscamos √2. Definimos f(x)=x²−2 y f′(x)=2x. Tomamos x₀=1.5.

xn+1 = xn − (xn²−2)/(2xn)

Ejemplo 2 · Raíz múltiple y método mejorado

Resolver (x − 2)² = 0

Aquí la raíz x=2 tiene multiplicidad 2. Si expandimos:

f(x)=x²−4x+4    f′(x)=2x−4    f″(x)=2

Para comparar, el método clásico usa:

xn+1=xn−f/f′

El mejorado usa:

xn+1=xn−(ff′)/((f′)²−ff″)

Con x₀=3, el clásico avanza hacia 2 más lentamente, mientras que el mejorado puede recuperar un comportamiento mucho más rápido para esta raíz múltiple.

Ejemplo 3 · Función no polinómica

Resolver cos(x) − x = 0

Definimos f(x)=cos(x)−x y f′(x)=−sin(x)−1. Con x₀=0.5, las iteraciones se acercan a aproximadamente 0.739085.

xn+1 = xn − [cos(xn)−xn] / [−sin(xn)−1]
